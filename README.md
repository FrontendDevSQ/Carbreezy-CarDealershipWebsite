# Carbreezy

Carbreezy is a fully responsive, multi-page car dealership website built to deliver a smooth, real-world automotive browsing experience. From exploring the newest arrivals to browsing pre-owned vehicles by category, Carbreezy brings together clean design, intuitive navigation, and interactive features — all crafted with HTML, CSS, and JavaScript.

Whether you're a first-time buyer exploring options or just love scrolling through beautiful car listings, Carbreezy makes the journey simple, visual, and enjoyable.

# Features
- New Cars & Used Cars sections - browse fresh arrivals or pre-owned vehicles, neatly organized
- Brand-wise browsing - explore cars grouped by their manufacturers
- Category-based filtering - quickly narrow down results by SUVs, sedans, hatchbacks, and more
- Interactive car listings - click on any car to view detailed specs in a smooth pop-up
- Offers page - stay updated with the latest deals and discounts
- Car gallery - a visual showcase of vehicles in high-quality display
- About & Contact pages - learn more about the platform and get in touch easily

# Tech Stack
- HTML, CSS, JavaScript
